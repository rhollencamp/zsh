# Pixel Perfection textures

Block textures from **Pixel Perfection** by XSSheep, as maintained by the
community in **Pixel Perfection Community Edition**.

- Source: https://github.com/Athemis/PixelPerfectionCE
- Commit: `28e38cab7c1f03f86364ef704f705bebcc13cb3d`, from
  `assets/minecraft/textures/block/`
- License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/);
  the full text is in `LICENSE.md` next to this file
- Contributors to the pack: XSSheep (original author), StonePendant,
  freejusticehere, Stingraych, Nova_Wostra, lazerl0rd and Athemis

The PNGs here are unmodified copies. `npm run atlas` packs them into
`public/atlas.png`, which is an adaptation and is therefore also licensed
CC BY-SA 4.0. Grass tops and leaves are tinted at render time.

To add a texture, copy it here from the same source (check the pack's
`content_with_issues.md` first), then run `npm run atlas`.
